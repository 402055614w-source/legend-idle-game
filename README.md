# 传奇挂机小游戏

传奇风挂机小游戏，三职业自动打怪升级，挑战祖玛教主。

## 作品介绍

这是一款向经典传奇致敬的挂机小游戏，全部内容装在一个 HTML 文件里，双击就能玩，不用装任何东西，也不用联网。玩家选一个职业，在玛法大陆上自动打怪、攒金币、升装备，等级够了就进更深的地图，最后挑战祖玛教主。游戏最大的特点是省心：战斗全自动，血瓶蓝瓶自动喝，进度自动保存，关掉页面再回来还能领一份离线收益，适合碎片时间玩两下。

游戏的灵感来自传奇类游戏的挂机玩法：打怪、掉金、升级、换装、打 Boss，一条线走到底，没有复杂的系统和强制任务，打开就能玩，玩几分钟就有正反馈。界面是复古传奇风格，暗色底配金红点缀，手机和电脑都能玩。

## 玩法

开局从战士、法师、道士里选一个职业，之后战斗全自动进行，怪物会一波波刷出来，角色自动攻击、自动喝药、自动拾取金币和经验。玩家要做的事只有三件：到等级了换更高级的地图，在铁匠铺花金币升级武器和防具，药不够了去药店补货。杀怪数累计到 30 只，祖玛教主就会降临，击杀后给大量金币和经验。

## 三职业

战士血厚攻高，近战之王，烈火剑法偶尔打出爆发伤害，站得住打得久，是最稳的挂机职业；法师魔法攻击全场最高，一发雷电术伤害惊人，但血薄皮脆，全靠药水撑；道士攻防均衡，自带治愈术，每回合回复生命，最省药、最耐耗的挂机职业。三个职业共用同一套战斗循环，只是属性和技能分支不同，各有各的打法。

## 四张地图

比奇城野外 1 级就能进，是新手练级的地方；骷髅洞 5 级解锁，怪物开始变硬；僵尸矿洞 10 级解锁，掉金明显变多；祖玛寺庙 16 级解锁，是最高级的挂机点。每张地图有 4 种怪物，各有血量、攻击和掉落，等级不够的地图会被拦截并提示所需等级。地图越深，怪物越强，收益也越高。

## 装备与药品

武器和防具各有十档，从木剑布衣一路升到顶级装备，全部用打怪攒的金币在铁匠铺升级，每升一档攻击和防御都实打实上涨。红药金创药和蓝药魔法药可以在药店购买，战斗中血量或魔法不足时自动喝，药尽了角色会阵亡回城复活，不会丢装备和等级，复活后继续挂机。

## Boss 与战绩

每杀 30 只怪物，祖玛教主就会降临，血量 810，红色战场加 Boss 标签，击杀后掉落大量金币和经验，是前期升级最快的路子。顶栏常显等级、职业、金币、杀怪数和 Boss 击杀数，战绩一目了然。

## 存档与离线收益

进度用浏览器 localStorage 保存在本机，刷新页面或关掉浏览器都不会丢，重开后点继续游戏就能接着玩。关掉页面期间按离线时长结算挂机收益，上限 8 小时，再次打开时弹窗展示，回来就有收获。

## 技术架构

纯前端单页应用，零后端、零依赖、零构建：一个 index.html 包含全部界面、样式和逻辑，游戏引擎分为战斗、地图、装备、Boss、存档五个模块，数据存在浏览器 localStorage 里。玩家用手机或电脑浏览器打开页面即玩，运行方式是双击 index.html，或用 python3 -m http.server 起一个本地静态服务。

直接双击 index.html 用浏览器打开，或者在项目目录执行 python3 -m http.server，再访问 http://localhost:8000。
